## Upload to GitHub

1. Sign in and open https://github.com/mohiuddin723/dth_2026_wabsite
2. Select the master branch. Choose Add file > Upload files.
3. Drag the CONTENTS of this extracted folder into GitHub: index.html, assets, pages, build.cjs, LICENSE, README.md and .nojekyll. Do not upload the ZIP or an enclosing folder as the website.
4. Commit the upload to master. This replaces matching files and adds the third article. Old unused images/scripts can remain; the new site does not load them.
5. Open Settings > Pages. Under Build and deployment, use Deploy from a branch, master, / (root), and Save if needed.
6. Wait for the Pages deployment to succeed in Actions, then visit https://mohiuddin723.github.io/dth_2026_wabsite/ and refresh. Test all three navigation links and references.

The .nojekyll file may be hidden by your computer. Enable hidden files when uploading, or create an empty file named .nojekyll in the repository root with Add file > Create new file.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
