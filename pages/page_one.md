# The benefits of OSS:

Open source software is more than just a free download. Under its license, users can inspect, edit and redistribute code, provided the conditions outlined in the licence are met (Open Source Initiative, n.d.). Researchers can look at how a tool handles evidence as opposed to following the claims of its developer. This will involve technical skills, but will support scrutiny and accountability.

Software may also be modified to fit various requirements. LibreOffice invites participation in the translation, documentation and development process (LibreOffice, n.d.). Students may write assignments without having to purchase a software licence. Local needs could be addressed through changes commissioned by a municipality. Users can thus have an influence on development.

Having access to code also means decreasing reliance on one organisation. Others can pick up the project if development halts, using a fork, a new version of the project using existing code. But people and resources are needed. While open source provides opportunities for continuity, it does not provide guarantees. Researchers can also adapt tools and make them available for colleagues to consider their approaches.
