# Zotero for European Studies

Zotero is the software that collects, organises and cites research sources. It was developed at George Mason University's Roy Rosenzweig Center for History and New Media but is now part of the Corporation for Digital Scholarship (Zotero, n.d.a). I could structure articles and EU documents by theme and create references for a European Studies literature review on international students' European belonging. All imported information would still require verification.

## Five project checks

Licence: GNU AGPL version 3 (see COPYING file). It allows free use, modification and redistribution under its terms. These include the requirement for source sharing in the distribution of covered software and providing modified versions for remote network interaction (Zotero, n.d.b).

Last update: 10 November 2026, the newest commit in the main-branch was made on 9 November 2026, UTC (Zotero, 2026). Recent activity indicates continued development, but does not mean reliability.

On that date, the main repository on the GitHub API had 90 contributor accounts (excluding anonymous contributors Zotero, n.d.c). The figures in this historical count do not imply that everyone is still active.

Questions: User support mainly takes place in forums. During an installation discussion in LibreOffice, a member of the Zotero team pointed out a problem and proposed a solution (Zotero Forums, 2026). Engagement is demonstrated here but a single example does not demonstrate overall response quality.

Funding of development, maintenance, support and service infrastructure (Zotero, n.d.d) is provided by money gathered through Storage subscriptions from individuals and organisations. There is still a need for financial support for free software.

## Verdict

I would use Zotero for a thesis, and double check references and make back-ups. It is active, supported and funded thus giving reasons for confidence. Export provides an alternative way to another reference manager, but some fields and existing citation links are not guaranteed to be preserved. Migration should be tested; therefore, export is not a complete backup (Zotero, 2025).
